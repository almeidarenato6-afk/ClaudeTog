# Store assets

Ativos e documentos legais necessários para publicação nas lojas. Ver checklist completo em [`../docs/PUBLISHING_CHECKLIST.md`](../docs/PUBLISHING_CHECKLIST.md).

```
store-assets/
├── privacy/
│   ├── PRIVACY_POLICY.md   # modelo — revisar com jurídico antes de publicar
│   └── TERMS_OF_USE.md      # modelo — revisar com jurídico antes de publicar
├── icons/                    # PENDENTE: arte final da TogPlay (ver docs/BRANDING.md)
│   ├── android/               # mipmap adaptativo (foreground/background), 512x512 Play Store
│   ├── ios/                    # AppIcon.appiconset, 1024x1024 App Store
│   ├── wearos/                  # ícone de relógio
│   ├── watchos/                  # AppIcon watch
│   └── garmin/                    # launcher icons por família de dispositivo
└── screenshots/               # PENDENTE: capturas reais de dispositivo por plataforma
```

Nenhum binário de ícone/screenshot foi gerado neste commit — arte final depende do manual de marca oficial da TogPlay (hoje placeholder, ver `docs/BRANDING.md`). As pastas acima documentam a estrutura esperada para quando a arte estiver pronta.
